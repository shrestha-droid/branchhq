Proof, not promises

Nothing is handed over on trust.

Most AI builders stop when the code looks right. Branch HQ keeps going until the app has been run and made to do its job. If a check fails, the specialist gets the real error and fixes it.

  • Hardcoded secrets and keys
  • Plaintext passwords, unsafe cookies
  • Routes that don't match between site and server
  • Database changes that would break existing data

  • Checks it does what was asked
  • Records an explicit verdict

A record nobody can quietly rewrite

Every decision, chained and witnessed.

Install

Up and running in two minutes.

Branch HQ isn't signed with a paid publisher certificate yet, so your computer asks you to confirm it once.

  1. 1

    Open the download and drag Branch HQ into Applications.

  2. 2

    Open it. When macOS says it can't verify the app, click Done, then go to System Settings → Privacy & Security and click Open Anyway. Only the first time.

  3. 3

    Add a model in Settings: a free Gemini key from Google AI Studio, a Claude or OpenAI key, or your own model server. For the fastest previews, also install Node.js 22.5 or newer.
