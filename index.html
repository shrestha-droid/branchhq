Secure by default

Protections that are enforced, not requested.

Asking an AI to "be secure" is not a guarantee. These are built into every server it makes, or checked on every change — code that fails them does not ship.

Built into every server

  • Security headers on every response
  • Cross-site access locked to the site's own address
  • Error details hidden from visitors, kept in the server log
  • Staff login checked on the server, never trusted from the browser
  • Sensitive fields encrypted in the database

Blocked before it ships

  • Keys or passwords written into the code
  • Passwords stored without hashing
  • Database queries a visitor could inject into
  • Permissions the browser grants itself
  • Keys hiding in git history, flagged when you open a project
