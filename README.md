# Branch HQ

**AI writes the code. Your auditors get the proof.**

Branch HQ is a desktop app that builds and changes software with a team of AI specialists. Every change reaches your repository as a pull request that records what checked it:
- the security scan
- your tests
- an independent review
- the model that wrote it
- who approved it

Its Health Check finds the mistakes AI-built apps ship with, at the exact file and line, without using an AI model:
- open Supabase tables
- admin keys in the code
- secret keys sent to the browser
- injection holes

Website: https://shrestha-droid.github.io/branchhq

## Your code stays on your computer
- Projects, chats, settings and the audit record are stored locally.
- Keys are encrypted with the operating system's keychain.
- With a local model, nothing leaves the machine.
- No analytics or tracking.
- What the app connects to, and how to turn each connection off: [For IT](https://shrestha-droid.github.io/branchhq/it.html).
