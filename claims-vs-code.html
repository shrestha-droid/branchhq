Contradicts the answer

How this was produced

  • The code side comes from Branch HQ's Health Check: fixed rules, no AI model, and the same code always gives the same result.
  • Keys are never shown in full.
  • Each check is recorded in a tamper-evident log, so the evidence can be shown later exactly as it was found.
  • The code stays on our machine and is deleted when the work is done.

What this does not cover

  • Settings changed only in the Supabase dashboard; worth confirming there.
  • Business-logic flaws, and anything a manual penetration test would find.
  • This is evidence for a security review. It is not a certification.
